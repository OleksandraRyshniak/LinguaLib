# LinguaLib – Language Learning App

LinguaLib is a cross-platform application designed to help users learn foreign languages through reading books, translating unfamiliar words, and practicing vocabulary.

The application was developed using .NET MAUI and C#.

## Features

- Read books in different languages
- Translate unfamiliar words while reading
- Save new vocabulary to a personal dictionary
- Practice vocabulary using interactive flashcards
- Track reading progress
- Add and manage books
- Search and manage saved words
- Switch between light and dark themes
- Multilingual interface (English, Estonian, Russian)
- Background music settings

## Technologies

- C#
- .NET 10
- .NET MAUI
- XAML
- SQLite
- MVVM Architecture
- REST API (MyMemory Translation API)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/OleksandraRyshniak/LinguaLib.git
   ```
2. Open `LinguaLib.slnx` in Visual Studio.
3. Install the required .NET MAUI workloads.
4. Restore NuGet packages.
5. Select a supported device or emulator.
6. Build and run the application.
